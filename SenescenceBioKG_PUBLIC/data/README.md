# Public data

All CSV files are UTF-8 encoded. The canonical graph is frozen at 654 nodes and 1,868 supported edges. Public evidence metadata has 1,868 records and deliberately omits `Evidence_excerpt`.

- `nodes/`: canonical entities.
- `edges/`: supported relations and non-verbatim evidence metadata.
- `ontology/`: entity and relation definitions used by the frozen release.
- `queries/`: competency-question definitions, final results, benchmark metrics, and graph-derived discoveries.
- `figure_source/`: final source CSVs for Figures 1–7 and supplementary analyses. Any file derived from the frozen manuscript master rather than a core edge retains that qualification in its original filename or documentation.

Source PDFs and bulk verbatim passages are outside this release because of copyright restrictions.
