# License selection (author action required)

No license has been assigned automatically. The authors and their institutions should confirm the licensing strategy before public release.

## Code options

- **MIT:** short, permissive, and compatible with broad reuse; includes a warranty disclaimer.
- **Apache-2.0:** permissive and includes an explicit patent grant and notice requirements.
- **GPL-3.0:** requires redistributed derivative software to remain under the same copyleft license.

## Data options

- **CC BY 4.0:** permits reuse and adaptation with attribution and is commonly used for research datasets.
- **CC0 1.0:** maximizes unrestricted reuse but may be inconsistent with institutional or contributor preferences.

Code and data may use separate licenses. Confirm ownership, institutional policy, contributor consent, third-party restrictions, and journal requirements. Source PDFs and verbatim evidence passages are not part of the public release and are not licensed by this repository.

Before release, add the selected license files, update README metadata, and replace all `TO_BE_COMPLETED` fields in citation and Zenodo templates.
