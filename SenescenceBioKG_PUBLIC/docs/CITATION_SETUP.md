# Citation setup

Before the first public release:

1. Confirm the final author order, spelling, affiliations, and ORCID identifiers.
2. Copy `CITATION.cff.template` to `CITATION.cff`.
3. Replace every `TO_BE_COMPLETED` field.
4. Add the selected software license identifier.
5. After GitHub–Zenodo archiving, add the version DOI. Retain the Zenodo concept DOI in the README for citation of the evolving project when appropriate.
6. Add the associated publication DOI when available.
7. Validate the file using GitHub’s citation rendering or a CFF validator before creating the release.

Do not publish the template as if it were complete: placeholder authors and DOI values are intentionally invalid.
