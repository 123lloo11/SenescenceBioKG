# Versioning

SenescenceBioKG uses semantic versioning for public releases.

- **MAJOR**: incompatible changes to identifiers, ontology semantics, or public file contracts.
- **MINOR**: backward-compatible additions such as new studies, nodes, edges, queries, or derived analyses.
- **PATCH**: documentation, presentation, or code fixes that do not alter the frozen scientific edge set.

The planned manuscript release is `v1.0.0`. Each release should record data and code checksums, graph counts, query benchmark status, R/Python environments, and changes from the preceding version. Never rewrite a released tag; publish a new version.
